# Перелёты с пересадками

Учебный проект (вариант 23). Java 21, Maven, JUnit 5.

## Модель
- `Airport` — аэропорт (IATA-код, часовой пояс); равенство по коду.
- `Flight` (record) — рейс; расписание в местном времени, арифметика через `Instant`.
- `Segment` (record) — рейс + `CabinClass` (enum с полями и телами констант).
- `Route` — неизменяемый маршрут; проверка минимальной стыковки; суммарное время/пересадки.
- `Timed` — sealed-интерфейс с полиморфным `duration()`.
- `RouteException` — проверяемое исключение с причиной (`Reason`).
- `RebookingService`, `Booking` — отмена сегмента и поиск замены (повышенный уровень).
- Деньги — `long` в копейках.

## Запуск
    mvn clean package
    java -jar target/flights-1.0.jar

## Тесты и javadoc
    mvn test
    mvn javadoc:javadoc

## Решения
- сравнения — через `Instant`, поэтому линия перемены
  даты и переход на летнее время обрабатываются без особых случаев.
- `RouteException` проверяемое: ожидаемая деловая ситуация, вызывающий код обязан её обработать.
- Ключ равенства аэропорта — код IATA (стабилен и уникален), бронирования — `BookingId`.
